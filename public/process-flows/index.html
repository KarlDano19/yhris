Job PostingProcess Flow

Job Posting handles the full lifecycle of creating, publishing, and managing job vacancies — from a multi-step creation wizard through tracking hired applicants and automatically closing filled positions.

  1. Click Create → complete the 8-step Job Form wizard: 1) Job Info (Country, Language, Job Title, Position, Advertise Locations — max 10) → 2) Job Type (Job Type, Work Setup, Schedule, Hire Count ≥1, Hire Date) → 3) Salary & Benefits (salary type/range, rate, Show Salary toggle, benefit chips, Show Benefits toggle) → 4) Job Description (file upload and/or rich-text Role/Qualifications/Notes, Skills tags, visibility toggles) → 5) Job Settings (Video Intro toggle; Screening Questions — minimum 3, presets or custom, must-have/show-to-candidate flags; Rejection Settings with personalized rejection feedback) → 6) Post As (default or custom poster image) → 7) Preview (read-only summary) → 8) Platform (post to LinkedIn/Facebook — required, optional Job URL).
  2. Navigate to Job Posting History — filter by date range or search (matches Title, Position, Type, Schedule, Work Setup), and switch between tabs: All Jobs / Active / Inactive / Drafts. Table columns: Job No., Date Created, Job Title, Position, Job Type, Job Schedule, No. of Hires Needed (“✓ Full” badge or “N remaining”), Work Setup, Assigned Users, Actions.
  3. Submit — button reads Share when creating and Save when editing; publishing generates a shareable public application link. In edit mode, each step also has its own Save button so changes can be saved without finishing the wizard.
  4. Drafts auto-save as you go (backend + local browser storage) and can be resumed via Load Draft; a draft is a separate, not-yet-submitted resource — not a status of a live job posting.
  5. System auto-creates 5 default hiring stages: Recommended Applicants → Initial Interview → Manager Interview → Panel Interview → Final Interview.
  6. Manage jobs from the list row: Edit, Duplicate, Delete (or bulk-select rows and Delete Selected), Assign Users, and a ⋮ More menu with Share Post To (Facebook/LinkedIn/Indeed/Instagram/Twitter), Set as Active/Inactive, and Hide/Show toggles for Roles, Salary, Benefits, and Notes/Remarks. Right-click a job title for a quick Active/Inactive toggle. A job posting only has a boolean Active/Inactive state — there is no separate status field.
  7. Applicants visit public job board, fill application form, answer screening questions (no login required).
  8. Screen applicants on Kanban board — drag-and-drop or use Pass button to move through stages. At Final Stage, Pass marks applicant as Hired and creates onboarding record.
  9. When hired count reaches required slots, job auto-deactivates.
Default Hiring StagePosition
Recommended ApplicantsStage 1
Initial InterviewStage 2
Manager InterviewStage 3
Panel InterviewStage 4
Final InterviewStage 5 (always last ★)
ℹ️
Deleting a stage auto-archives all applicants in it and marks them Rejected. Slot count cannot be reduced below the current hired count. The Final Stage is always locked as last and cannot be reordered.

Screen ApplicantsProcess Flow

Screen Applicants is the main hiring workspace — a Kanban board where applicant cards move left to right through hiring stages. Each job posting has its own board with configurable stages, team members, and per-stage requirements.

  1. Navigate to Screen Applicants → select job posting → Kanban board shows applicants per stage.
  2. Add applicants manually: First name, Last name, Email (required); Middle name, Resume (optional). Auto-placed in Stage 1 with Ongoing status.
  3. View applicant profile via 4 tabs: Applicant Information | CV/Resume | Screening Answers (Good Fit / Poor Fit badges) | AI Summary (Generate Summary).
  4. Move applicants by drag-and-drop or Pass button (→ next stage with email notification; at Final Stage → marks Hired, creates onboarding record, may auto-close job).
  5. Schedule interviews: Video (Zoom/Google Meet/Custom Link), Phone, or In-Person. Set date, time, duration, interviewers.
  6. Update status: Hired | Rejected (email sent) | Pooling | Archived (hidden, restorable) | Deleted (soft, restorable before purge).
  7. Manage stages: Add, Rename, Reorder (Final Stage ★ always last), Set Requirements (checklist), Assign Team Members with per-stage permissions.
Applicant StatusMeaning
OngoingActively in consideration
HiredTriggers Onboarding
RejectedRemoved; rejection email sent
PoolingKept for future openings
ArchivedHidden; fully restorable
DeletedSoft-deleted; restorable before purge
ℹ️
First time HR opens an applicant’s profile, system auto-sends “Your application has been viewed” email. Deleting a stage auto-archives all applicants in it and marks them Rejected.

Employment Approval FormProcess Flow

The Employment Approval Form (EAF) formally approves a new hire's employment before onboarding. HR Admin creates the EAF, which routes through a configured multi-stage approval chain. Each approver reviews, writes a recommendation, and provides a digital signature before approving or rejecting.

  1. Pre-requisite: HR Admin configures Approval Stages in Settings → Approval Stages (shared with Employee Movement PMFs). At least one stage with an assigned approver is required before EAFs can be created.
  2. Navigate to Recruitment & Onboarding → Employment Approval Form → Create EAF. Fill: Employee Name, Position, Employment Type, Date of Hire, Department, Salary Rate (all required), plus optional Remarks.
  3. Submit → system generates a unique Ref #, timestamps the submission, activates Stage 1, and sets status to Pending.
  4. Assigned approver reviews the EAF, writes a Recommendation, provides a digital signature (drawn or uploaded PNG/JPG), and clicks Approve or Reject.
  5. If approved and more stages remain, the next stage activates automatically. If this was the final stage, EAF status becomes Approved.
  6. If any stage is rejected, all remaining stages are cancelled and EAF status becomes Rejected immediately.
  7. Click any EAF row to view the full approval chain including all approver names, recommendations, decisions, and digital signatures. Click Print / Export to PDF.
OutcomeFinal StatusResult
All stages approvedApprovedEmployment formally approved; EAF archived as immutable audit record
Any stage rejectedRejectedRemaining stages cancelled; no employment changes made
⚠️
Rejection decisions are final and cannot be reversed. The HR Admin must create a new EAF if the approval needs to proceed. EAFs cannot be deleted once any approver has acted.

OnboardingProcess Flow

Onboarding triggers automatically when an applicant is marked Hired in Screen Applicants. HR guides the new hire through 5 steps ending with payroll enrollment. Onboarding records are never created manually — they are always system-generated.

  1. Step 1 — Assign Location, Department & Employment Status: Click Assign → select from dropdowns (or + Add New) → confirm. Locks to “Assigned.” Must complete before Step 5.
  2. Step 2 — Send Employment Contract: Send → email compose opens → Send. After signed contract returned, click Receive. States: Send → Resend → Receive → Received.
  3. Step 3 — Orient the New Hire: Orient → select method (Manual Orientation currently available; DOLO Training App and Other Platforms coming soon). Locks to “Oriented.”
  4. Step 4 — Introduce to the Team: Introduce → email compose → Send. Receive after team acknowledges. Same state flow as Step 2.
  5. Step 5 — Enroll to Payroll: Enroll → validates Step 1 is complete. Integrated (SSO) accounts auto-sync to payroll; password-only accounts recorded in HRIS only. Locks to “Enrolled.”
Status FieldTracks
Location & Department AssignedStep 1 completion
Contract Sent / ReceivedStep 2
Orientation CompletedStep 3 completion
Introduction Sent / ReceivedStep 4
EnrolledStep 5 completion
⚠️
Step 1 must be completed before Step 5. Onboarding records are created automatically when an applicant is marked Hired — HR never adds them manually. Test the dependency: attempt Step 5 before Step 1 to verify the blocking behavior.

Employee ListProcess Flow

Employee List is the master employee data management module — supporting full CRUD, CSV bulk import/export, column customization, and Active/Inactive filtering. All employee records created here are referenced across Onboarding, Screen Applicants, DOLE, and other modules.

  1. Navigate to Manage → Employee List — table defaults to 5 rows/page, active employees only.
  2. Search by name (2-second debounce); filter by Active/Inactive toggle and hire date range.
  3. Click + CREATE → fill required fields: Date Hired, First Name, Last Name, Email, Address, Gender, Location, Position, Department, Employment Status.
  4. Import employee list via CSV — required columns: Date Hired (mm/dd/yyyy), First Name, Last Name. Max file size: 10 MB.
  5. Export employee list: click CREATE → Export — accept the Data Export Agreement on first use; subsequent exports skip this step.
  6. Customize visible columns via the cog icon — 14 total columns available, 9 shown by default. Use Reset to restore defaults or Show All to display all 14.

Audit LogsProcess Flow

Audit Logs gives administrators a full record of every system action — who did it, when, and what changed. Includes an Email Monitoring tab that tracks every system-generated email and its delivery status.

  1. Navigate to Audit Logs — page opens on the Audit Logs tab by default.
  2. Review the logs table — columns: Unique No., Date and Time, Action (CREATE/UPDATE/DELETE), User, Module, Status.
  3. Apply filters: date range (both From and To required together), keyword search, or Advanced Filter dropdowns (Action, User, Module).
  4. Click any row to open Audit Log Details panel — view Data Comparison (Previous Data in red / New Data in green). Toggle “Show Only Changes.”
  5. Export filtered logs: chevron button next to Advanced Filter → Export.
  6. Switch to Email Monitoring tab to track system emails (columns: Unique No., Date/Time, User, Module Name, Status). Click any row for delivery details (To, Cc, Bcc, Scheduled).

Employee SeparationProcess Flow

Employee Separation allows HR to formally record and track an employee’s exit through sequential steps — separation letter, signed documents, last pay, quitclaim — until fully finalized. Each step must be completed in order before the next becomes available.

  1. Navigate to Employee Separation — defaults to Unfinished. Search by name, date range, or status.
  2. Click + Add Separation — fill: Date of Separation, Employee Name, Position (auto-fill), Department (auto-fill), Reason of Leaving.
  3. Separation Letter: Create → choose letter type → edit content → Generate. Then Send (email with PDF). Mark Received after employee acknowledges.
  4. Sign Documents: Send → attach one or more document files → email sent with attachments. Receive after signed documents returned.
  5. Last Pay: Release → fill pay details → attach payslip/computation.
  6. Quitclaim: Sign → attach document → Submit. Receive when physical quitclaim returned.
  7. Once all steps complete, status changes to Separated and record is archived.
Form FieldRequired
Date of SeparationYes (date picker)
Employee NameYes (searchable dropdown)
PositionAuto-filled (read-only)
DepartmentAuto-filled (read-only)
Reason of LeavingYes (free text)
⚠️
Once the Quitclaim is signed or received, all earlier steps lock permanently. Deletion is permanent and cannot be undone — test deletion scenarios on test data only.

Talent SearchProcess Flow

Talent Search lets employers browse, search, filter, favorite, compare, and email registered applicants in the talent pool — no specific job application required. Search state is auto-saved to browser localStorage.

  1. Open Talent Search — browse all profiles under “All Available Profiles” (photo/initials, name, gender, most recent position, skills), loading more via a Load More Profiles button. Search, tags, filters, and starred tags are all auto-saved to browser localStorage.
  2. Tag-based search: type a keyword and press Enter/Tab to add it as a chip. Multiple tags = OR logic. Field-specific syntax: skills:Python, education:Computer Science, work_experience:Manager. Click the Star on a tag to pin it as required (prefixes it with +, AND logic).
  3. Click Filter for structured filtering: Location (multi-select, up to 10 Philippine regions), Gender, Salary Range (7 tiers). Apply Filters / Clear All / Cancel.
  4. Click View Profile on a card to open Profile Details: Location, Nationality, Contact Number, Email, Education, Skills, Expected Salary, and a Work Experience list.
  5. Click the Bookmark icon on a card → add/remove Favorites (employer-scoped, server-persisted). View saved profiles via the floating Saved Profiles button, which opens an inline panel on the same page.
  6. Click Compare on 2 or more cards (up to 5) → a toolbar shows the selected count → Compare Selected opens a side-by-side profile modal plus a “Quick Comparison” bar-chart section (Experience count, Skills count, Salary).
  7. Send Email from the profile → fill To, CC, BCC, Subject, Body (rich text), select email template. Send Now or Schedule (future date/time), with up to 5 additional follow-up emails. Track all sends via the floating Email History button (separate page: status Sent/Pending/Failed, date filters, bulk delete).
Search SyntaxSearches In
skills:Skills list
education:Education history
work_experience:Work experience
Star a tag / prefix +Requires the term (AND logic)
ℹ️
Location is only searchable via the Filter modal, not as typed tag syntax. Compare is capped at 5 profiles. Deleting a Pending email record cancels the queued send. Deleting a Sent record only removes the log — the email has already been delivered and cannot be recalled.

YAHSHUA CONNECT — Gig Marketplace Last Updated: 2026-05-22
🔗

YAHSHUA CONNECTGig Marketplace

YAHSHUA CONNECT is an integrated gig marketplace with two modes. Personal Mode is for applicants/workers — browse the job feed, apply to postings, track application status, clock in/out, submit daily progress reports, browse trainings, view transaction history, and chat directly with clients. Business Mode is for clients hiring workers — post jobs, review and hire applicants, track work and pay hires, or (as a worker) find and accept work, track earnings, and manage jobs. Navigation is via the FloatingMenuBar — Home/Feed, Notifications, Chat, and Profile.

📋

Overview

Gig marketplace integrated with YAHSHUA HRIS; no separate login required. Personal Mode covers browsing/applying/working as an individual; Business Mode covers posting jobs/hiring and finding/doing work as a business account.

  • Personal Mode: browse jobs, apply, track status, clock in/out or submit daily progress, browse trainings, view transactions, chat.
  • Business Mode: post jobs and hire, or find work and get hired — track earnings/spending, manage active jobs, chat.
  • FloatingMenuBar: Home/Feed, Notifications, Chat, Profile.
